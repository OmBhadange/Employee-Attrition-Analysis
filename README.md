# Employee Attrition Analysis

**Employee Attrition Problem Definition and Planning using HR Analytics**

## Project Overview

This project focuses on understanding employee attrition using HR analytics and exploratory data analysis (EDA).

The objective is to study employee-related information, identify attrition patterns, and understand factors associated with employees leaving an organization.

## Project Objectives

- Understand employee attrition and HR analytics.
- Explore the HR dataset.
- Create a feature dictionary.
- Identify the target variable.
- Perform exploratory data analysis.
- Analyze employee attrition patterns.
- Identify business KPIs and ethical considerations.

## Dataset Information

**Dataset:** IBM HR Analytics Employee Attrition & Performance

- Total Records: 1,470
- Total Features: 35
- Target Variable: Attrition
- Problem Type: Binary Classification

Dataset Source: [IBM HR Analytics Dataset – Kaggle](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)
